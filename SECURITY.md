# Security scope

This is a single-user local developer preview. Keep the HTTP API on loopback and use a dedicated test Vault before adopting it. Origin checks and closed request bodies are not a replacement for authentication on a network service.

The public package excludes credentials, personal databases, vault contents and production relay configuration. Enabling a subscription provider intentionally allows the selected material to reach that configured provider. Repository trials restrict capabilities; they are not a claim that arbitrary untrusted programs are safe.

Please do not post exploitable details, secrets, private URLs, vault contents or database dumps in a public issue. Use GitHub's private vulnerability reporting if available on this repository. No response SLA or bug bounty is offered at this stage.
